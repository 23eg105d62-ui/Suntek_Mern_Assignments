### Week 2 - JavaScript Intermediate Concepts

##  Project Overview

This repository contains JavaScript programs developed during Week 2 practice sessions.

The programs focus on:

* Data creation and manipulation
* Deep copy and shallow copy concepts
* Age calculator
* Collection module usage
* Simple E-commerce operations
---
## Topics Covered

## 1. Data Creation
   
Programs for creating and managing:

* Arrays
* Objects
* Nested data structures

## 2. Deep Copy & Shallow Copy
   
Implemented:

* Shallow copy using spread operator
* Deep copy using structured cloning / JSON methods
* Difference between deep and shallow copy

## 3. Age Calculator
   
Program to:

* Calculate age using date of birth
* Display years, months, and days

## 4. Collection Module
   
Programs using JavaScript collections:

* Map
* Set
* WeakMap
* WeakSet
  
## 5. E-Commerce Project

Basic e-commerce functionalities:

* Product data handling
* Cart operations
* Price calculations
* Product filtering

## ## Technologies Used

* JavaScript
* Node.js
