### Week 3 - Product Backend Development

 ## Project Overview

This project contains the backend implementation for product management using JavaScript and Node.js.

## The backend performs:

* Product data handling
* API creation
* CRUD operations
* Server-side functionality

## Features Implemented

1. Product Management
* Add products
* View products
* Update product details
* Delete products
  
2. Backend Development
   
Implemented backend using:

* Node.js
* Express.js
  
3.  CRUD Operations

Performed:

* Create
* Read
* Update
* Delete
  
4. API Handling
   
Created REST APIs for:

* Product listing
* Product updates
* Product deletion
* Product creation
  
5. Technologies Used
* JavaScript
* Node.js
* Express.js
* Postman (for API testing)

6. API Functionalities
* GET → Fetch products
* POST → Add new product
* PUT → Update product
* DELETE → Remove product
